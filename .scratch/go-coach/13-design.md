# 13：整局扫描与逐手本地分析（第一纵切片）

Execution: done

依据：desktop-review-scope.md，用户选择导入后自动整局扫描、逐手按需中文讲解，并要求继续。当前交付只实现本地整局扫描和可查看的真实引擎结果，不冒充桌面版或DeepSeek讲解已经完成。

## 主代理决定

### 流程及模块

- 沿用已确认的浏览器完整用户流程测试seam；真实界面上传→后台扫描→走势/逐手选择→原谱回放及已有分支。业务状态、规则、历史、序列化、服务和引擎响应校验均真实执行，自动化只控制外部引擎进程/平台I/O。桌面生命周期另立任务，不在本切片引入新的测试seam。
- 新增整局复盘module（例如FullGameReview.tsx），由main按上传代次挂载，不能随回放step卸载。interface仅为已解析game、当前step、onStep、自动扫描开关；扫描调度、结果、错误、进度封装其内。业务测试不访问内部状态。
- 导入前可见“导入后自动整局扫描”复选框，默认开启；用户可关闭保留仅回放/手动分析。自动扫描仅连接同机回环服务，无互联网调用。更新main原有“仅显式打开才发送”的文案，清楚说明导入后默认发送必要棋局到本机。
- 新增只读同源能力查询（例如GET /api/engine-capability），只返回是否配置本地引擎，不泄漏路径/环境变量，不启动GPU。无配置时说明未配置并保留回放，不对每个局面反复失败；配置错误则实际分析明确失败。保留Host/Origin检查，不扩大源码白名单。
- 首版复用POST /api/analyze和已有KataGo核验，不新建整局服务器任务协议，不改变引擎多回合协议。必要时提取EnginePanel的NDJSON客户端传输，供扫描复用；严禁修改底层棋规或绕过position/result校验。新增浏览器module逐一追加白名单。

### 调度、身份及资源

- N手棋分析N+1个局面（含初盘、末手后）；不能只扫描精选局面。每次请求带初盘、初始方、RU/KM/HA和该点前的完整有序历史，绝不带名字/评论/原始SGF。
- 每个整局module同时最多一个扫描请求；按当前选中step及其前一局面优先补齐，随后继续未分析项。切手只调整下一任务，不取消仍有价值的在途扫描，避免产生取消风暴。已有手动变化请求保留原四个未收尾请求限额；本切片不做跨标签共享调度/持久缓存，忙时明确暂停而非无限重试。
- 暂停、取消/换谱/组件卸载立即使当前结果代次失效并中止自有请求；恢复必须是显式操作。任意分析失败暂停队列，显示失败局面和原因；用户可重试失败项再继续，不能自动为剩余所有手反复重启故障引擎。
- 状态用有区分的待处理/分析中/成功/失败；成功数、总局面数、暂停/完成/失败清晰，启动600秒与单次查询30秒不是整局期限。整个扫描无虚假固定耗时承诺。
- 每次成功返回附服务端生成的不透明engineSession：唯一服务实例＋已加载引擎进程generation，来自KataGo，不接收浏览器填写。不改原引擎身份核验和退出/重试所有权。它只用于同一存活进程分析的兼容性，并非持久模型指纹或未来AI证据ID。
- 结果仅保留当前上传会话内（最多2000局面）。为防最坏候选体积，将成功结果保留root及前10个已核验候选，并明确总候选数/显示数/丢弃数；不能偷偷截断进度。失败不缓存为成功，换谱全部清除，往返已分析手直接复用而不重新请求。
- 如果后续返回的engineSession与缓存不同，清除旧成功结果并明确提示引擎会话改变，保留本次新结果、重新扫描其余局面；绝不拼接不同代次的走势或计算前后差。服务重启、引擎崩溃重试不能因model文件名相同就误复用旧结果。首版不跨上传/跨进程/跨运行持久缓存，避免提前发明模型指纹与磁盘策略。

### 指标和呈现

- 走势固定BLACK：黑方胜率0–100%、目差正值黑领先；仅绘制已成功局面，未知区段断开，不插值冒充结果。图上点或相应手数列表能定位到真实回放；提供键盘可用的逐手入口及文字数值，不仅颜色/画布。
- 第k手的比较绑定实际执棋方及P[k-1]→P[k]。黑方目差下降=前黑目差−后黑目差；白方=后黑目差−前黑目差。胜率下降同理，用百分点（乘100），负值照实呈现。例：前0.60/+2.5、后0.45/−1.5，黑手下降15百分点/4目；若同样变化来自白手则为−15百分点/−4目。明确称“行棋前后估值变化”，不是严格的最优手损失或因果证明。
- 根估值、实际visits和条件可见；初盘没有上一手变化；任一端未成功/分析会话或profile/komi/bonus不一致不计算差值。100 visits/2秒低预算会有波动，小变化不自动贴恶手标签，不为失误设未经验证阈值；可列“估值下降较大、建议复查”的手数，不等同已核验教学价值。
- 当前第k手后的棋盘显示该局面的下一手候选，明确轮到谁。若显示第k手的实战比较与落子前推荐，必须明确标注来自第k−1手后局面，不能在已落子的棋盘假称下一手推荐。保留SGF/GTP坐标和假设PV，不伪造战略原因。
- 展示“DeepSeek中文讲解尚未接入/未启用”及后续入口说明，不能用示例、固定提子话术或数字摘要冒充已完成中文讲解。本切片不发任何在线请求、不读取Key。
- 原回放、四类示例教学、变化、真实引擎面板、木质棋盘保持可用。第一切片可用独立整局区域接近回放，不必一次重构整个页面；保留后续桌面布局空间。
