## Problem Statement

个人围棋新手希望在Windows电脑上，对已结束的19路对局边看棋盘边与中文教练连续交流：理解实战问题，比较另一种下法，试下后继续追问，而不是反复得到彼此孤立的逐手说明。

现有程序已经支持合法回放、本地整局分析、变化及可信依据；17已完成单棋盘明亮棋馆工作台并通过[主代理验收](17-main-acceptance.md)，不再是纵向面板，但仍缺少真正连续聊天和本机复盘存档。聊天必须知道问题说的是哪盘、哪手、哪条变化；资料、旧回答和有限引擎估计不能冒充当前有效证据。长对话需要压缩工作上下文，而不是偷偷截断或因金额预算停止。

## Solution

采用已选“明亮棋馆”工作台：左侧单棋盘，底部回放与紧凑走势，右侧连续聊天；详细候选和依据按需展开，窄窗切为“棋盘 / 教练”。启动先显示最近复盘，用户选择继续或导入新谱。本地保存可删除，原SGF不被改写。

只有发送聊天问题才触发回答；切手只是浏览，不自动提问、不取消原问题。每条问题绑定发送时的棋局/变化，新问题排队。发送授权该问题在明确范围和运行硬限内的必要模型请求、资料查询、有限棋局补查及上下文压缩，不再逐模型请求弹窗。

正常对话按序承接历史，接近窗口时压缩较早已完成讨论，保留近期原文、当前问题和棋局依据；完整原文仍本机可回查。RAG提供可追溯参考，Skill组织任务方法，棋规与KataGo提供局面事实/估计，程序负责权限、合法性和有效性约束。没有费用预算或金额预留；调用仍会产生实际用量。

## User Stories

保留原1–42编号的领域对应关系；历史验收以当时留档解释。40、41金额预算要求撤销，新增故事从43起编号。

1. As a 围棋新手, I want 只复盘已结束对局, so that 我学习而非在真人对局中获得辅助。
2. As a 围棋新手, I want 在Windows桌面使用复盘工作台并保留浏览器流程, so that 我能在主要下棋设备上学习。
3. As a 围棋新手, I want 手动导入完整19路SGF, so that 讨论围绕我选择的棋谱。
4. As a 野狐用户, I want 知道实际兼容性是否核验, so that 我不把参考研究当作兼容承诺。
5. As a 围棋新手, I want 非法或无法解析的棋谱被明确拒绝, so that 系统不会捏造棋局继续分析。
6. As a 围棋新手, I want 缺少规则等必要条件时明确说明, so that 不会把静默猜测当事实。

8. As a 围棋新手, I want 仍可进入每盘目标1–3个的精选教学局面, so that 我能选择集中学习而非被迫逐手阅读，找不到适合内容时不凑数。

## Implementation Decisions

### 当前能力与实施范围

已验收合法导入/回放、基础预设教学与变化、精选入口、本地引擎、整局扫描、Windows宿主、服务端依据、离线凭据配置和试下依据。尚无连续在线教练、复盘聊天存档、精确答案缓存、窗口压缩、RAG或方法加载。现有示例数据不能冒充在线模型。

本轮依次交付17工作台、18存档/身份、19连续聊天/请求保护，再从19推进20压缩、21资料/方法、22有限补查。05/08按实际验收映射收尾；06/07和10/11/12保留原依赖，不因本轮完成而自动关闭。旧任务编号与验收记录不得删除或追溯改写为新功能已完成。

### 工作台与局面

复用当前React/SVG棋盘、合法回放和引擎能力，不另写棋规或将棋盘烘焙成图片。主工作台只展示一张操作棋盘；原谱、推荐变化和自由试下有明确身份，可回到原谱。比较实战与推荐必须来自相同落子前局面及行棋方，显示标记不等于真的同时落两子。推荐变化不混入原谱未来或实战替代手。相同落点合并说明，pass用文字，无候选/PV/有效分析则明确缺失。

浏览状态与会话/回答生命周期分离。输入/消息不随当前手面板重挂而清空；消息引用可回看其局面，但后台完成不擅自移动当前棋盘。现有精选教学保留为明确的可选入口，不伪装成教练回复。

### 复盘身份与持久化

服务端复算规范棋谱和变化，登记稳定身份；不信任客户端hash、棋盘帧、数值或来源标签。规范内容需包括规则、贴目、让子、初盘/行棋方与完整有序主线；同谱判断忽略姓名、注释、路径，并保留规范内容核对，不只比手数/布局。会话和消息独立标识，同谱允许显式新建另一会话。

原文档案、可见消息和模型工作上下文分层。持久化具版本/大小校验、单写者、可见失败和有界读取，选型须在存档切片设计中固定并验证打包/恢复。删除范围包含本会话消息、摘要、分支及派生数据，不碰原SGF和凭据。重启将未完成处理标为中断，不恢复旧网络流或自动重发。存档中的旧分析仅为历史，不绕过当前引擎会话、有效期及完整前缀核验。

### 模型出口与授权

main持凭据和固定官方HTTPS出口，普通业务页面、utility和模型工具无Key读取能力。不开放任意endpoint/redirect、shell、文件、URL或泛用MCP权限。既有凭据加解密期限、撤销代次、密文保存及退出约束不回退。

模型保持deepseek-flash、非思考、max_tokens=2000；接口能力须按当前已核验profile实现，别名不等于锁定快照。无真实输出时明确未启用，不用预设回复冒充模型。首版可采用非流式请求；引用/格式校验通过不等于中文因果解释已证明。

未来软件明确展示发送范围后，用户发送即授权该问题所需的必要模型请求、摘要和受限工具续请求；不再逐模型请求弹窗。每次实际请求仍由程序检查问题身份、范围、取消/凭据代次及运行限制。允许字段为当前问题、本盘对话、必要棋局/有效分析、所用资料和方法；不自动附带原始SGF、姓名、注释、文件路径，自由文本可能含私人信息，不能宣传自动匿名。取消费用预算不等于免费或无限调用。

### 队列、取消和运行限制

同一会话按序处理问题；新问保存点击发送时快照，不把它偷偷注入旧回答。待处理消息可撤回，草稿不会因队列满而丢失。浏览切手不取消原问题；明确停止、删除会话、关闭程序或切换另一复盘会话后，不再为旧处理启动新请求。已发送的远端计算不保证撤销或免费，迟到内容不能复活终态或覆盖别的局面。

主代理工程初值：同一应用实例最多一个在途模型请求；单会话最多8条待处理问题；每问最多6次模型请求（含最多2次摘要）、4次工具调用及2个新增引擎分析局面；单模型请求最多60秒，本问总处理最多180秒，无自动重试。以上是运行保护而非费用限额。后续切片可细化计数边界，但不得静默放宽；触限明确停止/说明现有材料，不补造答案。幂等按消息/尝试身份处理，不靠按钮disabled防重复。

### 连续上下文与压缩

正常长度按顺序传递本盘历史，不默认裁成近期几轮。当前问题及当前局面单独绑定，不能从摘要或旧聊天猜。明确提及旧手可回到该讨论，有真正歧义才澄清。

接近模型窗口时只压缩早期已完成讨论；保留近期完整问答、当前问题、未完成工具协议和当前有效依据。摘要带原消息范围、局面引用、已讨论结论/不确定性及未决问题，不升格为系统授权或棋局事实。工具调用与结果保持协议配对。压缩不删除原文，用户可从正常历史界面回查；摘要失败不提交半成品替换。

压缩水位须按所选模型经核验的容量及计数方式留出输出/工具空间，所有摘要请求自身也须适配。计数方法、误差处理和保留边界在该片设计中固定，不称字符估算为精确token，不靠发送超限原文补救。不得在测试中私降内部阈值、塞假历史或用专有compact API替代真实业务。单条输入过大、没有可压缩内容或连续失败时诚实提示容量问题，不无限摘要。

### 资料、方法与补查

首批资料采用少量来源/许可明确的公开材料，正文、图谱、翻译/改编和再分发权分别核对；当前候选报告不是已批准教材。中文内容与适用规则需审校。检索首先在本地完成，不引入远程embedding；短中文词不能因检索器限制被默默漏掉。工具返回资料身份、原文片段、出处、版本及适用边界；无命中不编造引用，引用存在不等于结论已获支撑。

方法用于组织解释、同起点比较、试下核验和缺证据表达，可用短方法直接提供，不为名义上的Skill强加调用。资料、历史和方法不改变系统权限。只允许本盘已登记起点的合法有限变化补查；真实棋规、引擎条件和依据签发均由程序核验，已有有效结果优先复用，不把短PV当死活证明。

## Testing Decisions

沿用已确认的最高seam：真实浏览器操作→真实本地HTTP与业务，以及真实打包Windows exe。仅控制外部引擎、AI传输与平台I/O；不mock会话、上下文、棋规、依据、检索、授权或限制业务，不加私有window接口/产品假AI按钮。不依赖LLM逐字快照，测试用户可观察行为与受控出口内容。

已有145项网页、56项桌面是16基线的验收证据，不冒充后续修改结果。每片逐行为RED→GREEN、独立Spec/Standards、主代理检查真实diff并整合复测；UI另按必读附件进行真实渲染和视觉审查。具体旧记录见各任务，不以测试数量代替语义覆盖。

| 场景 | 必须观察的行为 |
| --- | --- |
| 工作台在1440×900、初始1280×900、窄/矮窗及长消息 | 单主棋盘，主要回放/输入可用；消息独立滚动，窄窗页签不丢局面/草稿；键盘和焦点可操作，不把输入框方向键当回放命令。 |
| 实战/推荐、同点、pass、无PV、合法试下及返回 | 同起点/同执棋方，不混原谱未来，状态和缺失信息准确。 |
| 导入、重导、重启、恢复、新建、删除 | 稳定身份，原谱/变化可复算，旧记录不被覆盖，错误可见；不自动展开私人聊天、发模型请求或复活旧依据。 |
| 问45手后浏览80手、再排队问80手 | 原答仍属45手，新问保留自己的快照，浏览本身零模型请求，不乱跳棋盘。 |
| 停止、撤回、删除、退出、凭据撤销、重复/迟到 | 不再启动未授权续请求，不覆盖新问题；已发送不误称未发送/免费；重启不自动重发。 |
| 连续追问与超长对话 | 出口可见真实历史/当前问题及正确依据；通过正常UI累计合法长消息跨生产同一压缩水位，先摘要再续答，早期原文仍可回查。失败不丢原文，不私改阈值或存储造条件。 |
| 检索与方法 | 真正检索本地批准资料，可打开片段/出处；无命中、资料版本变化和恶意指令不会伪造引用或扩大权限。 |
| 补查工具 | 合法、非法、重复、越界请求经真实业务核验；次数/时间限制和取消有效，结果属于准确分支/条件。 |
| 数据外发边界 | 受控出口观察白名单及问题授权，元数据/路径/Key不被自动带出；不据此宣称自由文本完美匿名。 |

真实KataGo搜索质量、DeepSeek教学棋理、野狐兼容性与学习成效仍由对应授权/验收票验证。受控测试不证明这些结果。不得占用、复用或停止用户5173服务。

- 本轮真实Key读取、私人棋谱/聊天外发、付费推理、真实GPU运行、推送与发布。
