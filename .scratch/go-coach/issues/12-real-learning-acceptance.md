# 12: 跑通真实复盘并验证学习体验

**Parent:** 围棋赛后复盘教练：第一版需求规格

**Category:** enhancement

**What to build:** 用户用真实授权棋谱完成精选教学、变化探索、追问、核验练习与跨盘复查，记录真人新手学习体验和实际成本、耗时，仅修复本流程的窄集成问题。

**Blocked by:** 07：跨盘记住问题并安排复习；10：接入真实在线 AI 讲解；11：验证真实野狐棋谱导入

**Status:** ready-for-agent

**Execution:** pending

## Acceptance criteria

- [ ] 在获准环境用真实授权棋谱从浏览器跑通精选、引导教学、变化、追问、核验练习及跨盘记录，核对真实服务证据，不用假响应冒充集成。

- [ ] 真人新手逐个学习目标 1–3 个局面，记录可理解性、教学推荐合理性及证据可靠性；没有合适内容时如实反馈，不凑数。

- [ ] 记录完整复盘与整盘分析、分支分析耗时、试下响应和真实体验；约 10–15 分钟只作为目标，未达到时报告事实而非保证。

- [ ] 结合真实用量、计价、在途并发及滞后计费证据复查月度新增服务 50 元保护；不得为验收故意超支，无法安全计量则停止并保留未验证。

- [ ] 真人在不同的核验同类局面中独立选合理落点并说明理由，记录所需提示与表现；一次答对和原题旋转不算掌握或迁移证明。

- [ ] 通过后续实际对局复查相似问题及记录对下一盘选点的影响；没有后续迁移证据时标待验证，不能宣称已经教会。

- [ ] 覆盖无合适局面、无核验练习、证据不足和真实外部失败的如实呈现，隐私、授权和预算保护始终生效。

- [ ] 各前置票浏览器测试继续通过；本票补完整集成回归并记录窄修复验证。发现超出窄集成修复范围的缺陷则记录阻塞，不无界重写。

## Testing decisions

最高 seam 为浏览器完整复盘与跨盘流程；已有各票测试是持续基础，本票不是唯一测试票。自动化可控外部 adapter 仅验回归，真实运行、成本和真人学习观察另列证据；不用精确 LLM 快照或流程通过宣称棋理全对、用户已学会。

## External prerequisites and decisions

需另获真实棋谱使用、运行、在线上传及付费授权和真人新手参与同意，具备已确认练习核验、掌握及迁移判断办法；确认实测环境与记录范围。依赖完成不代表当前授权，缺后续对局或真实费用结算证据时相应验收保持待验证。 外部前提与方案确认不属于新增任务编号依赖；未获对应授权时不得实测或标为已完成。

## Scope boundaries

仅真实体验验收及窄集成修复，不新增课程、平台、实时辅助或未批准功能；不以受控演示、短期试用夸大迁移成效，超范围缺陷回报主代理处理。 本次只创建任务文档，不授权实施、安装、外发、付费、提交或发布。
