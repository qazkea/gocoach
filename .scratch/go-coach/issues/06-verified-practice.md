# 06: 用核验过的同类局面练习

**Parent:** 围棋赛后复盘教练：第一版需求规格

**Category:** enhancement

**What to build:** 用户完成一个局面的教学后，尝试少量经核验的同类基础局面，独立选点并说明理由，获得有依据的反馈；没有合适练习则保持待验证。

**Blocked by:** 02：完成一个局面的引导式教学

**Status:** ready-for-agent

**Execution:** pending

## Acceptance criteria

- [ ] 浏览器从已完成教学进入同类基础练习，使用前可追溯练习来源、核验依据及与当前教学的同类关系。

- [ ] 用户能独立选择落点并提交理由，反馈同时评价落点合理性和理由，不只看是否命中某个坐标。

- [ ] 经核验合理的替代落点不会仅因不同于单一答案被判错；无法可靠判定的情况明确保留结论。

- [ ] 反馈对应可检查的棋子、关系或变化，不用未经核验的 LLM 造题并判对错。

- [ ] 没有合适的已核验练习时明确待验证，不以临时编题替代；当前没有现成题库的事实不被隐藏。

- [ ] 一次答对不立即标为掌握，原题旋转不计作迁移证据；反馈不声称用户已能跨局运用。

- [ ] 浏览器测试覆盖独立选点与理由、合理替代落点、错误或证据不足反馈及无题待验证，实际练习评判路径不被 fake。

## Testing decisions

最高 seam 为浏览器教学后练习。预期须来自独立核验练习与判分依据；仅外部分析或 AI 可用可控 adapter，不能替代真实练习选择和反馈业务。不以精确 LLM 文案判定，也不把离线通过当真实教学有效。

## External prerequisites and decisions

实施者必须在实施前取得并核验少量合法来源练习，与主代理及用户明确核验手段、同类定义、适用性、合理替代答案及理由判分依据；没有这些则报告阻塞，不假设已有题库。实施及外部操作授权另行取得。 外部前提与方案确认不属于新增任务编号依赖；未获对应授权时不得实测或标为已完成。

## Scope boundaries

仅有限基础同类练习，不扩展题库生产体系或课程，不以单次结果或旋转题宣称迁移。 本次只创建任务文档，不授权实施、安装、外发、付费、提交或发布。

Spec coverage: User Stories 31, 32, 33, 34.

## Comments

### 用户确认的练习与理由边界

- 用户同意第一批采用少量自建基础局面，逐点列出气、连接和提子依据，经独立审查后才使用；不能核验就不判对错，不声称职业棋手认证。
- 用户同意先用“选点＋标出依据或选择理由”进行可核验作答；自由文字仅作为补充，无法可靠判定时标待验证，不做关键词匹配式自动正确判定。
- 沿用既有约束：一次答对不等于掌握，原题旋转不证明迁移；不调用真实AI来假装已有自由文字评判能力。
- 02依赖已解除。实际实施前由主代理明确少量样例、同类关系、合理替代落点及结构化依据判分；仍须浏览器TDD、独立审查和整合复测。
- 主代理提出仅含两道提子题的首批范围后，用户追问“啥意思，只有提子？布局、死活什么的呢”。这不是对具体范围的批准。06保持pending，暂不按提子-only方案实施或收尾；须先明确既定基础主题与布局教学/练习的覆盖。两道题的独立手算通过仅说明题目局部事实，不说明产品范围已满足。
