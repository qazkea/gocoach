# 19: 受保护的连续追问

**Parent:** [连续复盘教练实施规格](../spec.md)

**Category:** enhancement

**What to build:** 在真实工作台发送问题、取得正确棋局依据并调用受限模型出口，保存连续对话并承接下一问；浏览切手不取消原答，新问题按各自发送时快照排队，支持停止/撤回。外部AI替身仅用于验收，产品没有假AI模式。

**Blocked by:** 18；08A离线凭据、15/16可信依据（已验收）。本票联合交付08B请求保护与05连续聊天可控主线，不等待不存在的费用预算模块。

**Status:** ready-for-agent

**Execution:** pending

## Acceptance criteria

- [ ] 只发送聊天问题才启动回答；历史按序承接，当前问题和局面快照单独绑定，旧回答不冒充新局面或有效依据。

- [ ] 生成中切手不取消/改写原问题，不自动跳盘；新问题排队并保留发送时位置，队列满不丢草稿，待处理消息可撤回。

- [ ] 发送后仅在明确字段/工具范围与运行硬限内完成必要续请求，不逐请求弹窗；启动、恢复、单纯浏览不发模型请求。

- [ ] main固定官方出口与凭据隔离；每次请求核验授权、取消/凭据代次、服务来源及范围，普通页面/utility/工具不能读Key或指定任意地址。

- [ ] 外发只含已批准的问题/本盘对话、必要棋局/有效分析、资料/方法；不自动带原SGF、姓名、注释或路径，不宣称自由文本匿名。

- [ ] 停止、撤回、删除会话、换会话、退出、重复及迟到均有明确终态；不自动重试/重发，不把取消或网络失败说成免费或保证未发送。

- [ ] 当前消息和真实模型结果按所属会话保存/恢复，失败与未完成可辨认；精确缓存若提供，须绑定完整请求身份，不能按手数/盘面猜命中。

- [ ] 无Key/未启用/失败均明确；事实、引擎估计、AI策略解释和未知限制可分辨，格式/引用校验不被说成棋理证明。

- [ ] 真实浏览器→HTTP→会话/授权业务及打包exe→main出口验收，仅外部AI/引擎/平台I/O受控；不得mock历史、配对、队列或权限。

- [ ] 按主规格执行请求数/工具数/超时上界，无费用账本；本票尚未完成20时容量失败明确说明，绝不偷裁历史。完成后逐条核对05/08父票，不标10真实教学完成。

## Testing decisions

沿用已确认的完整浏览器/真实HTTP与真实打包exe seam，仅替换外部I/O，不新增内部业务测试seam。每行为RED→GREEN；独立Spec/Standards及主代理整合验收。界面相关实现必须读取主spec列明的规范性附件并核对真实渲染，不只照截图做静态页面。

## Scope boundaries

允许本任务本地实现、测试和限定提交/分支整合，不推送或发布，不读取真实Key/私谱，不调用真实模型/embedding或运行真实GPU，不操作用户5173。新增依赖或范围突破先报告主代理；不夹带用户原有改动。
