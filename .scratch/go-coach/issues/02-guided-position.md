# 02: 完成一个局面的引导式教学

**Parent:** 围棋赛后复盘教练：第一版需求规格

**Category:** enhancement

**What to build:** 用户从上传棋谱进入一个已核验局面，先试下、求提示或直接看答案，在棋盘证据支持下比较实战、教学推荐手和引擎推荐手，完成一次受控教学流程。

**Blocked by:** 01：上传棋谱并还原棋局

**Status:** ready-for-agent

**Execution:** pending

## Acceptance criteria

- [ ] 浏览器从上传棋谱进入一个有来源及核验依据的教学局面，外部分析等待可见，完成后才能呈现相应教学。

- [ ] 用户可以先试下、请求提示后继续尝试，也可以直接看答案；三个入口均完成当前局面教学。

- [ ] 实战落子、教学推荐手和引擎推荐手分别标注，棋盘与文字指向同一局面。

- [ ] 核验样例涵盖教学推荐与引擎首选不同：教学手仍合理且易理解执行，允许比较引擎更优下法，不声称教学手最强。

- [ ] 核验样例涵盖两类推荐相同：如实标注，不为制造区别故意推荐较差落子。

- [ ] 解释指向可核对的具体棋子、关系或变化；不以估值或棋谚代替理由，引擎推荐注明分析条件下的评估而非全局最优证明。

- [ ] 分析失败或证据不足时明确未完成或保留结论，不用旧证据或编造内容冒充成功。

- [ ] 浏览器自动化通过可控外部分析 adapter 驱动真实教学流程，验证以上选择与反馈，不将核验样例硬编码为所有棋谱的生产教学答案。

## Testing decisions

最高 seam 为上传后完成当前教学的浏览器流程。外部分析可控，真实试下、推荐呈现及证据关联不 mock；使用独立核验样例，不使用逐字讲解快照。离线响应仅证明受控流程，不证明真实引擎、真实 AI 或教学有效。

## External prerequisites and decisions

实施者须先取得并核验少量样例，向主代理提交并确认教学推荐合理性与证据核验办法、等待及失败处理。当前没有题库；真实接入与上传付费不在本票授权内。实施仍须另获授权。 外部前提与方案确认不属于新增任务编号依赖；未获对应授权时不得实测或标为已完成。

## Scope boundaries

只教一个核验局面，不做整盘精选、自由分支分析或真实服务接入；不把固定示例扩大为任意棋谱能力。 本次只创建任务文档，不授权实施、安装、外发、付费、提交或发布。
