# 07: 跨盘记住问题并安排复习

**Parent:** 围棋赛后复盘教练：第一版需求规格

**Category:** enhancement

**What to build:** 用户在实际教学与练习后留下轻量学习记录，下一盘优先关注反复问题，并通过后续实际对局复查是否能独立运用所学。

**Blocked by:** 04：每盘精选少量教学局面；06：用核验过的同类局面练习

**Status:** ready-for-agent

**Execution:** pending

## Acceptance criteria

- [ ] 浏览器完成真实教学及练习后，反复问题、实际选点与理由表现形成轻量学习记录，不预置虚假表现。

- [ ] 按确认保存策略重新进入并上传另一盘后，记录仍可用；持久化、读取及更新走真实业务路径。

- [ ] 有合适候选的下一盘教学优先级确实受既有反复问题与练习表现影响，且仍符合基础性、证据和少量精选约束。

- [ ] 浏览器可辨认本次教学与既往问题的关系；无合适新局面时不为复习凑题或捏造重复问题。

- [ ] 后续实际对局中复查相似问题，保留独立选点及理由与后续表现的证据；尚缺证据时显示待验证而非掌握。

- [ ] 一次答对及原题旋转不使记录变成已掌握，学习判断遵循另行确认的标准而非擅自固定次数。

- [ ] 保存或读取失败时明确反馈，不冒称记录已持久保存；浏览器跨次使用测试覆盖真实记录更新、恢复和下一盘选点变化。

## Testing decisions

最高 seam 为浏览器跨盘完整流程，包括教学、练习、退出后按保存策略再次进入与选点。外部分析及 AI 可控，不能 mock 学习记录或最终选点结果，不能直接查存储替代用户行为验收。通过仅证明记录流程，不证明真人掌握。

## External prerequisites and decisions

实施者在实施前向主代理和用户确认具体保存方式、保存策略与管理办法、掌握及迁移证据标准；不由此推导新账号功能。用核验的多盘样例验证，实施及必要操作仍须授权。 外部前提与方案确认不属于新增任务编号依赖；未获对应授权时不得实测或标为已完成。

## Scope boundaries

轻量记录与复习优先级，不做课程、每日计划、注册、自动同步或学习记录删除导出；可控跨盘表现不等于真实迁移证据。 本次只创建任务文档，不授权实施、安装、外发、付费、提交或发布。
