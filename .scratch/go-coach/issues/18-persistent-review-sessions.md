# 18: 本机保存和恢复复盘

**Parent:** [连续复盘教练实施规格](../spec.md)

**Category:** enhancement

**What to build:** 导入后建立可复算的棋谱/分支与稳定复盘会话身份，在本机保存原谱、变化和浏览位置；重启从最近复盘选择恢复，同谱重导先选择继续或新建，可删除本应用记录。为连续消息提供可靠归属，不填造聊天。

**Blocked by:** 17（统一主盘/变化状态）；14、15、16（已验收）。

**Status:** ready-for-agent

**Execution:** pending

## Acceptance criteria

- [ ] 服务端复算/登记规范棋谱与合法变化，不信任客户端hash、帧或来源标签；完整有序历史不同不能仅因盘面相同而合并。

- [ ] 重启先显示最近复盘，不自动展开旧私人聊天或发送模型请求；明确选择后恢复原谱/变化及位置。

- [ ] 同谱重导先选择继续或新建，新建保留旧记录；同谱内容判定与独立会话身份分开。

- [ ] 本机持久化有版本、单写者、大小/读取边界；损坏、保存失败和不兼容数据明确提示，不偷偷变成空档案。

- [ ] 删除仅清本应用该复盘数据及派生数据，不删除原SGF、凭据或其他复盘；删除失败不误报成功。

- [ ] 恢复旧局面/聊天不复活已过期或其他引擎会话的分析引用；从规范历史重建棋盘而非信任存盘帧。

- [ ] 真实UI与打包exe覆盖导入、关闭重启、重导、恢复、新建、删除和失败；不通过私改存储或mock核心来代替正常流程。

- [ ] 存储选择及打包/挂起退出行为由设计明确并验证，不重新引入费用账本；主代理双轴审查和复测后验收。

## Testing decisions

沿用已确认的完整浏览器/真实HTTP与真实打包exe seam，仅替换外部I/O，不新增内部业务测试seam。每行为RED→GREEN；独立Spec/Standards及主代理整合验收。界面相关实现必须读取主spec列明的规范性附件并核对真实渲染，不只照截图做静态页面。

## Scope boundaries

允许本任务本地实现、测试和限定提交/分支整合，不推送或发布，不读取真实Key/私谱，不调用真实模型/embedding或运行真实GPU，不操作用户5173。新增依赖或范围突破先报告主代理；不夹带用户原有改动。
