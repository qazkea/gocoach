# 09: 接入真实围棋引擎分析

**Parent:** 围棋赛后复盘教练：第一版需求规格

**Category:** enhancement

**What to build:** 用户在网页对上传原局及试下分支获得真实引擎候选、主变化（PV）和估值，明确分析条件与局限，并能辨认等待、过期及失败结果。

**Blocked by:** 

必需：03：探索不同应对与变化。

条件：08：在线调用的隐私与预算保护——仅当选用联网或付费分析时额外受其阻塞；本地无外发且免费分析可不等待 08。这不是无条件依赖。

**Status:** ready-for-agent

**Execution:** done

## Acceptance criteria

- [x] 在经授权的选定环境中，从浏览器上传核验棋谱并分析原局，看到真实引擎候选、PV 和估值，而非仅完成 adapter 库或假响应。

- [x] 浏览器试下自己的落点及对手替代应对后获得真实分支分析；证据与该分支匹配，原实战不被改写。

- [x] 对选定版本实际核验规则、贴目、让子及已知历史传递和合法性，包含历史影响的样例；必要信息缺失不得静默猜测。

- [x] 真实输出的估值视角和分析条件可核对；推荐仅为给定条件下评估，不把候选等同全部合法手，不把 PV 等同必然结局。

- [x] 等待、外部失败与过期结果在浏览器中正确呈现；快速切换不让迟到结果覆盖当前局面，空或不足变化不伪造补齐。

- [x] 记录具体引擎版本、模型、搜索预算、运行环境及少量原局与分支实测证据，核对变化稳定性和响应，不仅凭文档推导可用。

- [x] 若选联网或付费分析，必须先满足 08 并另获相应外发、运行及付费授权；本地无外发且免费才可不等待 08。

- [x] 自动化仍可控制外部引擎来验证失败、乱序等行为，同时独立保留真实网页接入证据；不以离线通过替代实测。

## Testing decisions

最高 seam 为网页原局及试下分支。可控 adapter 的浏览器测试和少量真实接入验证分别报告；后者核对输入条件、输出语义与分支能力，防止 interface 漂移。真实引擎数值不证明棋理解释或教学难度，不需要 04 完成才验证。

## External prerequisites and decisions

实施者须在实施前与主代理及用户选择版本、模型、搜索预算和运行环境，取得必要安装及运行授权；KataGo 仅候选，其结构化分析不是现成 SGF 网页服务。联网或付费选择另需政策、计价、外发与付费授权；这些外部前提不能由依赖完成推断。 外部前提与方案确认不属于新增任务编号依赖；未获对应授权时不得实测或标为已完成。

## Scope boundaries

仅真实原局和分支分析，不要求整盘精选，不自行扩为自然语言教学；候选排名或人类落子概率不能当作已验证教学价值。 本次只创建任务文档，不授权实施、安装、外发、付费、提交或发布。

Spec coverage: User Stories 6, 18, 27, 28, 29, 30.
