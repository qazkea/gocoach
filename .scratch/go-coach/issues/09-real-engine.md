# 09: 接入真实围棋引擎分析

**Parent:** 围棋赛后复盘教练：第一版需求规格

**Category:** enhancement

**What to build:** 用户在网页对上传原局及试下分支获得真实引擎候选、主变化（PV）和估值，明确分析条件与局限，并能辨认等待、过期及失败结果。

**Blocked by:** 

必需：03：探索不同应对与变化。

条件：08：在线调用的隐私与预算保护——仅当选用联网或付费分析时额外受其阻塞；本地无外发且免费分析可不等待 08。这不是无条件依赖。

**Status:** ready-for-agent

**Execution:** in-progress

## Acceptance criteria

- [ ] 在经授权的选定环境中，从浏览器上传核验棋谱并分析原局，看到真实引擎候选、PV 和估值，而非仅完成 adapter 库或假响应。

- [ ] 浏览器试下自己的落点及对手替代应对后获得真实分支分析；证据与该分支匹配，原实战不被改写。

- [ ] 对选定版本实际核验规则、贴目、让子及已知历史传递和合法性，包含历史影响的样例；必要信息缺失不得静默猜测。

- [ ] 真实输出的估值视角和分析条件可核对；推荐仅为给定条件下评估，不把候选等同全部合法手，不把 PV 等同必然结局。

- [ ] 等待、外部失败与过期结果在浏览器中正确呈现；快速切换不让迟到结果覆盖当前局面，空或不足变化不伪造补齐。

- [ ] 记录具体引擎版本、模型、搜索预算、运行环境及少量原局与分支实测证据，核对变化稳定性和响应，不仅凭文档推导可用。

- [ ] 若选联网或付费分析，必须先满足 08 并另获相应外发、运行及付费授权；本地无外发且免费才可不等待 08。

- [ ] 自动化仍可控制外部引擎来验证失败、乱序等行为，同时独立保留真实网页接入证据；不以离线通过替代实测。

## Testing decisions

最高 seam 为网页原局及试下分支。可控 adapter 的浏览器测试和少量真实接入验证分别报告；后者核对输入条件、输出语义与分支能力，防止 interface 漂移。真实引擎数值不证明棋理解释或教学难度，不需要 04 完成才验证。

## External prerequisites and decisions

实施者须在实施前与主代理及用户选择版本、模型、搜索预算和运行环境，取得必要安装及运行授权；KataGo 仅候选，其结构化分析不是现成 SGF 网页服务。联网或付费选择另需政策、计价、外发与付费授权；这些外部前提不能由依赖完成推断。 外部前提与方案确认不属于新增任务编号依赖；未获对应授权时不得实测或标为已完成。

## Scope boundaries

仅真实原局和分支分析，不要求整盘精选，不自行扩为自然语言教学；候选排名或人类落子概率不能当作已验证教学价值。 本次只创建任务文档，不授权实施、安装、外发、付费、提交或发布。

### 网页实施方案已确认

- 主代理方案见09-design.md：同源回环Node服务＋独立真实引擎面板，不受示例匹配限制；实际规则/历史校验、进程协议和浏览器交互执行，只在测试中替换外部引擎进程。
- 计算使用显式KataGo近似profile、黑方视角、小预算；不满足半整数贴目或初盘/HA一致性条件时只拒绝估值，不削弱回放。HA不明的非空setup不自动猜测补偿。
- 选择有界并发（最多4未收尾请求）、失效/取消隔离、无效候选或PV整次拒绝；缺PV如实保留。exe/配置不从HTTP输入，同源与CSRF校验，64KiB请求上限，无个人字段/SGF外发。
- 接续既有本地实施与合成试跑授权，使用已校验资产完成少量真实浏览器原局/分支、白轮、规则/HA/劫历史及重复稳定性验证；不增加引擎/模型/依赖运行库下载，不调用在线AI。
