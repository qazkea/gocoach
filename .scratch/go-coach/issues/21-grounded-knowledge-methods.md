# 21: 有出处的资料与教学方法

**Parent:** [连续复盘教练实施规格](../spec.md)

**Category:** enhancement

**What to build:** 教练在连续问答中按需检索小型本地围棋资料，回答可打开相关原文与出处；短教学方法组织解释、比较和核验步骤，而不替代程序保护或当前局面证据。

**Blocked by:** 19；首批资料许可、实际内容与中文适用性核验（尚未完成，不影响17–20/22）。

**Status:** ready-for-agent

**Execution:** blocked

## Acceptance criteria

- [ ] 仅纳入逐项核验许可/来源/版本及中文内容的材料；正文、棋图/SGF、翻译和分发权不由根许可证笼统代替。

- [ ] 检索真实使用本地材料/索引，不只让外部AI替身返回伪资料；覆盖短中文词、相关片段、无命中及版本变化。

- [ ] 返回资料身份、片段、出处/许可和适用条件，原理与限制/关联棋例不被拆成误导结论；相似棋例不是本局证明。

- [ ] 正常UI可核对引用片段/来源，无命中不编造出处；引用存在不等于所有中文结论受支持。

- [ ] 短方法清楚说明所需依据、同起点比较和缺证据处理，已有适用方法不必每轮重读；不为名义Skill强加额外请求。

- [ ] 资料/旧对话中的指令不能获得系统权限，不能访问任意文件/URL、Key或扩大本盘工具范围。

- [ ] 无远程embedding或未批准抓书；请求/工具/长度硬限及取消由真实业务执行。

- [ ] 浏览器/HTTP与打包应用验收真实检索、引用和授权，独立内容/许可核验不能由假响应或静态代码审查冒充。

## Testing decisions

沿用已确认的完整浏览器/真实HTTP与真实打包exe seam，仅替换外部I/O，不新增内部业务测试seam。每行为RED→GREEN；独立Spec/Standards及主代理整合验收。界面相关实现必须读取主spec列明的规范性附件并核对真实渲染，不只照截图做静态页面。

## Scope boundaries

允许本任务本地实现、测试和限定提交/分支整合，不推送或发布，不读取真实Key/私谱，不调用真实模型/embedding或运行真实GPU，不操作用户5173。新增依赖或范围突破先报告主代理；不夹带用户原有改动。
