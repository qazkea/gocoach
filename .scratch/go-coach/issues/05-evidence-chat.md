# 05: 围绕当前局面文字追问

**Parent:** 围棋赛后复盘教练：第一版需求规格

**Category:** enhancement

**What to build:** 用户围绕当前棋盘输入想法、追问为什么或讨论不同应对，得到与当前局面证据对应的文字反馈；超出证据范围时明确保留结论。

**Blocked by:** 03（已完成）；15：服务端讲解依据；08：隐私与请求授权保护（费用预算已取消，真实按需讲解入口仍须授权）。现按17–22已批准图，19联合实现08B保护与本票连续聊天可控主线，20–22补齐压缩/资料/补查；不因工作台或单次逐手解释完成而自动关闭本票。

**Status:** ready-for-agent

**Execution:** pending

## Acceptance criteria

- [ ] 用户在浏览器输入自己的想法、询问某手好坏或提出不同应对，均能获得对应当前局面或分支的反馈。

- [ ] 回答指向具体棋子、连接关系或可检查变化，用户能在当前棋盘核对，而非只给坐标结论。

- [ ] 估值不被当作原因，棋谚不被当作证明；缺少证据时明确局限，不编造支持材料。

- [ ] 复杂布局和全局问题可以提出，但证据不足时保留结论，不暗中扩大基础教学能力。

- [ ] 追问等待和外部失败可辨认；失败不展示伪造回答或用旧回答冒充新回答。

- [ ] 提问后切换局面或分支，迟到及乱序回答不会覆盖当前教学，已展示回答的上下文可辨认。

- [ ] 浏览器自动化通过可控 AI adapter 运行真实提问、上下文与证据关联流程，覆盖正常、缺证据、失败及过期响应。

## Testing decisions

最高 seam 是浏览器当前教学中的文字追问；只控制外部 AI 与分析响应，不 mock 上下文和证据绑定业务。断言证据对应、保留结论与状态，不做 LLM 精确措辞快照。离线流程不证明真实 AI 棋理正确或能可靠教学。

## External prerequisites and decisions

实施者须在实施前与主代理确认回答证据与不确定性呈现、失败恢复办法。此阶段仅可控外部 adapter；真实上传及付费授权另办，不能因票完成推定许可。用户已批准17–22本地实施和限定提交/隔离整合。 外部前提与方案确认不属于新增任务编号依赖；未获对应授权时不得实测或标为已完成。

## Scope boundaries

仅围绕当前局面文字交流，不做语音或泛化全局专家；不进行真实在线调用，不宣称模型教学合格。 17–22本地实施与本任务限定提交/隔离整合已获授权；真实Key、外发、付费、真实GPU、推送和发布仍未授权。
