# 04: 每盘精选少量教学局面

**Parent:** 围棋赛后复盘教练：第一版需求规格

**Category:** enhancement

**What to build:** 用户上传一盘棋后，逐个学习少量有证据、基础且易懂的精选局面，而非按最大损失逐手灌输；没有合适内容时如实获知。

**Blocked by:** 02：完成一个局面的引导式教学

**Status:** ready-for-agent

**Execution:** pending

## Acceptance criteria

- [ ] 浏览器上传有合适教学内容的核验棋谱，看到分析等待后逐个进入目标 1–3 个精选局面，并完成已有引导教学。

- [ ] 真实选点逻辑同时考虑教学价值与新手理解、执行难度，不仅按掉目或胜率损失排序。

- [ ] 核验对照中最大损失来自复杂变化时，基础易懂且有证据的候选可优先；不能把引擎数值直接当难度或教学价值。

- [ ] 有限教学候选覆盖危险棋子、连接、吃子和简单死活；每个入选局面均能指出可检查证据。

- [ ] 没有适合局面或证据不足时明确说明，不为凑满数量生成内容或把复杂全局结论冒充基础教学。

- [ ] 1–3 个局面、约 10–15 分钟呈现为体验目标而非每盘保证，不提供逐手讲解整盘。

- [ ] 浏览器测试用可控外部分析返回候选输入，经真实选点逻辑得到结果；覆盖基础优先、逐个教学及无合适局面，不 fake 最终选择结果。

## Testing decisions

最高 seam 为浏览器上传至精选并教学。可控 adapter 只替代外部分析，不替代选点或教学业务；预期来自独立核验样例。自动化只证明受控选择行为，真实可理解性与用时另验。

## External prerequisites and decisions

实施者须向主代理提出并在实施前确认有限基础范围的判定、候选证据及可理解性核验办法、无局面交互；不得将待定指标说成成熟难度评分。实施另获授权，未要求真实引擎已接入。 外部前提与方案确认不属于新增任务编号依赖；未获对应授权时不得实测或标为已完成。

## Scope boundaries

不扩展复杂布局或全局教学，不增课程体系；本票可控验证不证明真实引擎或真人教学成效。 本次只创建任务文档，不授权实施、安装、外发、付费、提交或发布。
