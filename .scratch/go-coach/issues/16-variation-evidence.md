# 16：试下前后可信依据闭环

**Parent:** 围棋赛后复盘教练；连续聊天、RAG与教学方法实施方向

**Category:** enhancement

**What to build:** 用户在现有本地引擎面板试下后，可查看对应当前变化的本地可信依据，分清试下与实战；缺前驱分析、过期、失败和切换时不展示错误依据。为以后围绕试下连续追问补齐前置能力，不新增在线聊天或伪造模型回答。

**Blocked by:** 03合法变化、09本地引擎、15服务端讲解依据（均已验收）。不依赖尚未完成的08B，因为本片不含模型出口、外发或费用；05仍保留08依赖，不将本片标成05完成。

**Status:** ready-for-agent

**Execution:** done

## Acceptance criteria

- [x] 试下入口和详情明确原谱起点、变化手数，落子与前后候选文案不冒充实战。
- [x] 完整历史/规则/条件匹配才使用前后引用，同手数、同盘面不同历史不串用；最终由真实服务核验。
- [x] 提子、气和Pass来自真实棋规与服务端依据，不接受客户端估值冒充可信输入。
- [x] 前驱未完成或引用不可用时明确说明，不自动补跑分析。
- [x] 撤回、重走、改下、重新分析、换谱和关闭立即清除旧详情，迟到成功/失败不覆盖新选择。
- [x] 引擎失效和过期引用不复活；缓存有界且不跨面板/导入生命周期共享。
- [x] 复用已确认的完整浏览器/真实HTTP测试seam，只替换外部引擎和平台交付时机，不mock业务核验。
- [x] 既有实战依据和回放/变化测试通过，无新增真实外发、模型调用、Key读取、依赖或整体布局改造。

## Testing decisions
