# 01: 上传棋谱并还原棋局

**Parent:** 围棋赛后复盘教练：第一版需求规格

**Category:** enhancement

**What to build:** 用户在电脑浏览器手动上传已结束对局的完整 19 路 SGF，查看真实实战落子；错误或必要条件未定时得到明确反馈。随这一条行为建立最小可运行应用，而非独立脚手架工程。

**Blocked by:** None (can start immediately)。仍需另获实施授权。

**Status:** ready-for-agent

**Execution:** in-progress

## Acceptance criteria

- [ ] 在电脑浏览器上传一份有独立核对依据的完整 19 路 SGF，能逐步查看实战落子、提子和最终记录，不捏造缺失落子。

- [ ] 明确入口用于赛后复盘，不提供真人对局实时辅助、账号连接或自动同步。

- [ ] 无法解析、非 19 路或非法棋局得到可辨识反馈，不进入有效分析；拒绝样例不会呈现为成功棋局。

- [ ] 编码、结果、让子、规则、贴目和已知历史按实施前确认方案处理，并能与样例核对。

- [ ] 缺失规则、贴目等必要元数据时显式标明未确定，按确认方案补齐或拒绝，不静默猜测。

- [ ] 修正输入或再次上传合法棋谱后可查看正确记录，先前失败不污染新棋局。

- [ ] 首条浏览器行为测试随最小应用交付，覆盖成功还原与非法、必要元数据缺失反馈；记录实际运行结果。

## Testing decisions

以浏览器上传和棋盘可见实战为最高 seam，预期来自核验 SGF，不检查解析内部。真实解析和还原不能 mock；本票不需要真实引擎或 AI。

## External prerequisites and decisions

实施者在编码前向主代理提出并经用户确认语言、框架、测试方案及运行方式，确认 SGF 输入与缺失元数据处理策略；技术栈目前未选。核验样例须有合法来源。本次仅授权创建票，仍须另获实施及必要运行授权。 外部前提与方案确认不属于新增任务编号依赖；未获对应授权时不得实测或标为已完成。

## Scope boundaries

仅完成标准 SGF 的最小赛后入口和还原，不承诺当前野狐兼容，不提前实现分析或教学。 本次只创建任务文档，不授权实施、安装、外发、付费、提交或发布。
