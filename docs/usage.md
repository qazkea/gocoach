# Go Coach 使用指南

本指南介绍当前可用的本地赛后复盘功能。构建和启动见[项目首页](../README.md)。
在线中文教练与会话存档尚未接入；右侧草稿只在本次窗口编辑，不保存、不发送。

## 1. 导入与回放

选择已结束对局的 SGF；首次可用[四手合成样例](../tests/fixtures/manual-finished.sgf)。
文件在本机读取。未配置引擎仍能回放，不需要 Key。

- 默认勾选“导入后自动整局扫描”；配置有效时会开始本地分析。
- 只想回放或手动分析，可在导入前取消该选项。
- 聚焦回放区域后，左右方向键前后浏览，Home / End 到起始 / 末尾。
- 棋盘用 SGF a–s 坐标：`aa` 为左上，`ss` 为右下，先列后行。
- 小环标记最近一手；初盘和 Pass 不标。悬停预览不代表落点合法。
- 宽屏双栏，窄窗通过“棋盘 / 教练”切换，保留当前状态。

应用展示 `RE` 原记录；缺失时显示“未记录”，不由此判断真实胜负或对局是否已结束。

## 2. 配置本地 KataGo

### 准备配置文件

已核验范围是本机 Windows、KataGo **1.18.1 OpenCL** 与
`kata1-b18c384nbt-s9996604416-d4316597426.bin.gz` 模型。
服务会核对引擎版本；其他版本、后端、模型或机器不能沿用该验收结论。
应用不下载引擎 / 模型，也不安装驱动或运行库，需自行准备可信来源的文件。

在仓库外创建 UTF-8 的 `operator.local.json`，按实际位置替换以下四个字段：

```json
{
  "executable": "D:/local/katago/package/katago.exe",
  "model": "D:/local/katago/kata1-b18c384nbt-s9996604416-d4316597426.bin.gz",
  "dataDir": "D:/local/katago/web",
  "homeDataDir": "D:/local/katago/home"
}
```

所有路径必须是绝对路径；前两项是已有文件，后两项是已有目录。
`dataDir` 用于生成配置和诊断日志，`homeDataDir` 用于引擎缓存。
不要提交私密配置、密钥、私人棋谱或运行日志到 Git。

### Windows 桌面

1. 打开原生菜单 **引擎 → 选择本地配置…**，选中上述 JSON。
2. 应用校验文件、字段和路径；确认框会显示将运行的 exe 与模型，默认取消。
3. 仅批准可信配置。**批准会重启本实例服务并清空当前复盘**，分析中更换也需确认。

取消或配置错误不会破坏当前复盘。应用不修改原 JSON，也不复制引擎 / 模型。
配置引用与摘要保存在 Windows userData 下的 `go-coach/settings.json`，重启时检查恢复。
原文件更改、消失或路径失效后，需要重新选择并确认，不会静默启用。

桌面每次运行使用 userData 内独立的引擎数据目录，复用模型和 `homeDataDir`；
不与网页共享生成的分析配置。完整请求 / 响应记录被关闭，但可能保留引擎自身诊断日志。

### 浏览器预览

在启动服务的 PowerShell 中设置配置路径：

```powershell
$env:GO_COACH_CONFIG='D:/local/katago/operator.local.json'
npm.cmd run dev
# 或先构建，再运行生产服务
# npm.cmd run build
# npm.cmd start
```

默认访问 `http://127.0.0.1:5173`；占用时加 `-- --port 5174` 等空闲端口。
服务端改动或配置变更后重启自己的服务，不要停止他人的进程。
浏览器与本地分析共用 Node 服务；单独静态预览 `dist` 不等于完整引擎服务。
仅使用 `127.0.0.1` 地址，服务检查 Host / Origin。

引擎按需启动；关闭自动扫描后，仅回放、预设教学或能力查询不会启动 GPU。
网页默认不记录完整请求 / 响应，诊断日志位于 `dataDir/engine-logs`。
不要为私人棋谱开启 `recordSyntheticEvidence`；该选项仅用于明确授权的合成验收。

### 可分析条件

回放成功不保证可估值；分析额外要求：

- `KM` 在 [-400, 400] 内，按 0.5 递增（含整数）。
- 非空初盘必须记录 `HA`；`HA0` 或空盘缺 `HA` 使用零让子补偿。
- `HA≥2` 必须与纯黑初盘数量匹配且白先；Chinese 白方让子补偿为 N，Japanese 为 0。
- 使用近似规则 profile：简单劫、禁自杀；Chinese 为 AREA / NONE tax，Japanese 为 TERRITORY / SEKI tax。

这些不是完整国家规则或野狐认证。分析采用低预算；首次 OpenCL 调优可能较慢。
候选不代表全部合法手或最强证明，重复分析的首选也可能变化。

## 3. 扫描、对照与试下

### 整局扫描和走势

N 手棋扫描 N+1 个局面，从初盘到末手之后。成功结果仅在当前会话缓存，不持久化。
切手会优先安排当前及前一局面；暂停 / 换谱取消自有请求，旧结果不覆盖新棋谱。
配置、条件或分析失败及 busy 会明确暂停，不反复自动重启。
修正问题后点击“重试失败局面并继续”；自由试下面板可“重新分析当前局面”。

走势与数值固定 **BLACK（黑方）视角**：正目差表示黑领先，未知区段断开。
“行棋前后估值变化”比较该手前后，按实际执棋方计算下降，胜率单位为百分点，允许负值。
它不是严格最优手损失、因果证明或教学价值；条件不同、结果不齐全时不比较。
原谱走势不代表试下局面的估值。

### 同起点 S / A 与推荐变化

选择一手后点“同起点对照”，回到该手落子前，标记实战 S 与同方推荐 A。
两者只是落点标记，不是同时落两子；相同点合并，Pass 用文字表示。
分析详情的普通候选来自该手之后、轮到下一方的局面，不能与同起点候选混用。

点击 A 或“查看推荐变化”会重新核验本地依据，独立展开合法 PV。
变化不混入实战该手或原谱未来；缺 PV、依据失效或请求失败时不补造推荐。
PV 是假设变化，不是必然结局，估值不是棋理原因。

### 自由试下与讲解依据

“自由试下”从当前显示局面开始，支持双方连续行棋、Pass、撤回改下和“返回原谱”。
不会改写原谱；换分支清除旧估值，试下仍受下文有限棋规约束。

当前及前一局面分析齐备后，可“查看本手讲解依据”；初盘不要求前一局面。
试下分析详情另有“查看试下讲解依据”，核对完整历史及直接前驱，不只比较盘面或手数。
展示落子、提子、气及前后候选等本地事实，**不是在线中文策略解释**；气数不是活棋证明。

依据只在本地服务内存中有限期保存，观察 / 查询不会自动重算。
切手、换谱、引擎会话变化或连接失效会清除旧详情，迟到响应不能恢复旧依据。
快速连下造成前驱缺失时会明确缺依据，不自动补跑；过期需重新导入并分析。
静默网络阻塞不能保证立即发现。详细生命周期与限额见[本地依据验收](../.scratch/go-coach/15-main-acceptance.md)。

## 5. SGF 支持范围

### 文件与编码

- 只接受一棵树的一条序列，不截取集合、分支或损坏文件的一部分。
- 要求 `FF[4]`；`GM` 缺省 1、`SZ` 缺省 19，明示值仅接受 1、19。
- 同一个 game-info 节点须有 `RU[Chinese]` 或 `RU[Japanese]` 与有效数字 `KM`，该节点可不在根。
  缺失 / 未知规则或缺贴目需修改文件重传，不猜测或提供补齐表单。
- 最大 **1 MiB、2000 个节点**，包含注释和 setup 节点，并非可导入 2000 手；帧数不超过 2000。
- 接受 `CA[UTF-8]`、`CA[GBK]`、`CA[ISO-8859-1]` / `CA[latin1]`，大小写不敏感。
  无 CA 使用真正 Latin1，保留 0x80–0x9F，不按 Windows-1252 解码或昵称猜编码。
  严格解码后再处理 SGF 转义；未知 CA、坏 UTF-8 / GBK 字节拒绝，候选须与自身根 CA 一致。

### 初盘、行棋与有限棋规

- `AB/AW/AE` 可在根及第一手之前多个节点设置、覆盖、清空初盘，支持矩形展开。
  同节点不可重复 / 交叠，拒绝越界、反向或一格矩形；setup 与 move 不可同节点。
- 初始最终盘面不能有无气链；途中 setup / `PL` 拒绝。setup 不计手、不计提子，不臆造更早历史。
- `HA` 接受 0 或 2–361 整数，回放仅记录，不自动摆子，也不要求 `AB` 数量等于 `HA`。
  `HA≥2` 默认白先，否则黑先；第一手前最后一个 `PL[B/W]` 可覆盖。
- 交替行棋，禁止占点；先提敌方无气链，再判己方无气，禁止自杀。历史落点提空后可以再下。
- 简单劫禁止立即还原对方上一着之前的盘面。非立即全盘历史重复只报“暂不支持该循环规则”，
  不据此判所有规则下非法，也不自动判无胜负。
- `B[]` / `W[]` 和 19 路的 `tt` 都是 Pass，计一手；Pass 自身不参加循环拒绝。
  连续 Pass 不推断真实结束；不校验停止后死活确认、恢复对局等程序，不计分、不裁判终局争议。

### 属性白名单

处理棋局的属性：`FF GM SZ CA B W AB AW AE PL RU KM HA RE PB PW`。
接受但不参与棋盘 / 计分且暂不显示的描述属性：
`BR WR BT WT GN GC DT EV RO PC SO US AN ON TM OT C N AP ST`。

`AP` 限 `应用名:版本`，不支持字段内冒号；`ST` 限 0–3。
除 setup 点列表外，支持的属性均为单值；属性重复、根属性出现在非根、多个 game-info 节点均拒绝。
其他属性（含 `KO`、标注、时间剩余等）明确报不支持，不静默丢弃后称成功。
这是应用子集限制，不说明原文件违反 SGF 标准；尚未验证野狐导出兼容。
基础规则依据与手算样例见[样例核验说明](../tests/fixtures/README.md)。

## 6. 隐私、安全与验证边界

必要棋局仅送到同机回环分析服务，不发送名字、评论或完整原始 SGF。
没有账号连接、自动同步或持久棋谱 / 聊天存档；当前不向在线模型发送内容。
这不等于安装、打包或所有操作系统环境下绝对零网络访问。

原生菜单“讲解 → 配置 DeepSeek Key…”仅提供本机加密保存，不验证账户或调用模型。
**现在无需填写真实 Key；保存不代表在线讲解已启用或已授权发送。不要把 Key 发到聊天里。**
无法安全加密时不退回明文；可从讲解菜单删除凭据，普通复盘页面不能读取已存 Key。
本机加密不防同一 Windows 用户的恶意程序，也不保证内存抹除或跨机器恢复。

Windows 目录包未签名、未发布；保留整个目录，不能只移动 exe，不要关闭系统安全保护。
正常关闭会等待自有引擎退出；异常、失败或超时会报错并默认保留窗口。
再次明确选择按失败退出，不代表引擎已经安全回收；不会按端口 / 进程名杀其他实例。
强杀主进程、关机、断电等灾难场景未作完整验证。

验证仅覆盖记录中的 Windows 环境、指定引擎 / 模型及受控替身测试，不承诺跨机器或其他系统兼容。
自动化不替代真实文件选择器、人工双击 / SmartScreen、真人教学成效或 GPU 性能验收。
历史 GPU 脚本需重新核对当前入口及授权，不能作为现成的新版本验证命令。

命令见[项目首页](../README.md)。请在未设置真实 `GO_COACH_CONFIG` 的终端运行自动化，使用合成棋谱和外部引擎替身，不把真实配置或私谱带入测试。
