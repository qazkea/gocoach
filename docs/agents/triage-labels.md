# 分诊标签

| Matt 的类别/状态 | 本项目实际值 | 含义 |
| --- | --- | --- |
| bug | bug | 已有行为有缺陷 |
| enhancement | enhancement | 新功能或改进 |
| needs-triage | needs-triage | 待维护者评估 |
| needs-info | needs-info | 等待补充信息 |
| ready-for-agent | ready-for-agent | 规格清楚，可由 AI 实施 |
| ready-for-human | ready-for-human | 需要人工处理 |
| wontfix | wontfix | 明确不予处理 |

本地文件用 Category 和 Status 字段表示。每个已分诊反馈只有一个类别和一个分诊状态。
以上是分诊状态，不是完整的开发进度。实施进度和依赖按 issue-tracker.md 记录。
分诊先建议并等待维护者确认，不自动关闭或否决反馈。
